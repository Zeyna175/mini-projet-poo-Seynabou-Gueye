# Mini-projet POO — Une médiathèque en Python

**Auteur :** Seynabou Gueye

Gestion d'une petite médiathèque : documents (livres et DVD), adhérents, et prêts,
avec une conception orientée objet démontrant encapsulation, héritage,
polymorphisme et abstraction.

## Lancer la démonstration

```bash
python main.py
```

## Lancer les tests

```bash
pytest -q
```
